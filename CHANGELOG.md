# Changelog

## 1.0.0 - 2026-10-07

- Added dual-source direct-manager authorization using AD and Entra ID records.
- Added current-access classification with direct and transitive assignment evidence.
- Added AD account-expiry and contract-date mismatch warnings.
- Added explainable job-title, department, and location-based access suggestions.
- Added plain-text Service Desk drafts with no submission or remediation path.
- Added a responsive localhost browser interface and validated JSON API.
- Added restrictive browser security headers and local-only default binding.
- Added automated authorization, analysis, API, and safety-boundary tests.
- Added GitHub Actions continuous integration and architecture/security documentation.
